# libpackwunix

> Унифицированная библиотека управления системными (WSP) и пользовательскими (WPM) пакетами операционной системы Wunix.

## Возможности

- **SemVer (`version`)**: парсинг версий вида `0.4.2` и проверка ограничений зависимостей (`libwunix >= 0.2.0`).
- **Манифесты (`manifest`)**: разбор спецификаций `manifest.toml` с разделением на `type = "system"` и `type = "user"`, уровнями критичности (`critical`, `base`, `desktop`, `optional`) и триггерами.
- **Бинарный контейнер `WSP1` (`format`)**: 128-байтный заголовок прямого доступа с контролем смещений, цифровой подписью Ed25519, манифестом и архивным пейлоадом без полного копирования данных в память.
- **Репозитории (`sources`)**:
  - WSP: фиксированный адрес системного репозитория, задаваемый при компиляции.
  - WPM: динамическая конфигурация источников с прямым указанием серверов (`Server = URL`).
- **Конфигурация демона (`daemon`)**: разбор настроек `/etc/wsp/daemon.conf` для фоновой службы `wspd`.
- **Загрузчик (`kernel`)**: безопасная генерация `/boot/limine.conf` с текущим и резервным ядром.

## Поддержка платформ

- `no_std` + `alloc`: сборка для системного окружения Wunix (`x86_64-unknown-none`).
- `std` (по умолчанию): сборка для хостовых утилит и репозиторных серверов на Linux (Debian, Ubuntu).
